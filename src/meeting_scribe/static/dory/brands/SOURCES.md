# Integration icons: sources

Each file is the brand's own app icon or logo mark, used unaltered to identify the integration on the
command center's Integrations, Workspaces and account pages. Every mark is a trademark of its owner.
Collected 27 Oct 2026. Changes: only the SVG viewBox / padding (a square canvas, the mark centred), and
for Discord and WhatsApp the official white glyph placed on the brand-colour tile the way the brand's own
store icon shows it. The licence wording on each brand page was not re-checked when this file was written.
